# 串口功能模块说明

## 目录结构

```
serial_comm/
├── __init__.py           # 模块初始化
├── serial_config.py      # 串口配置和常量定义
├── serial_worker.py      # 串口读取线程（不阻塞UI）
├── port_scanner.py       # 端口扫描线程（不阻塞UI）
├── port_utils.py         # 端口枚举（含虚拟串口）
└── serial_manager.py     # 串口管理器（支持多串口，进程内单例）
```

## 核心功能

### 2. SerialWorker (serial_worker.py)
后台线程用于读取串口数据，避免阻塞UI线程。
- **原始帧透传**：不按 `\r`/`\n` 拆分、不 strip，0x0A / 0x0D 等字节原样送达
- 帧切分仅基于时间间隔（连续到达的字节合并为一帧，约 12ms 间隔）
- 单次读取上限 4096 字节，避免数据洪峰拖垮 UI

### 3. PortScanner (port_scanner.py)
后台线程按固定间隔（默认 2 秒）扫描可用串口，避免在 UI 线程调用
`list_ports.comports()` 造成卡顿。页面隐藏时线程停止，显示时重新启动。

### 4. PortUtils (port_utils.py)
`list_serial_ports()` 合并两个来源：
- pyserial 的 `comports()`
- Windows 注册表 `HARDWARE\DEVICEMAP\SERIALCOMM`

后者能列出 com0com 等虚拟串口（pyserial 枚举不到）。

### 5. SerialManager (serial_manager.py)
管理多个串口连接的中心组件（`SerialManager.instance()` 进程内单例）。

**主要方法**：
- `get_available_ports()` - 获取可用串口列表
- `open_port(config, port_id)` - 打开串口连接
- `close_port(port_id)` - 关闭指定串口
- `close_all_ports()` - 关闭所有串口
- `write_data(port_id, data)` - 向串口写入数据
- `get_connection_info(port_id)` - 获取连接配置信息
- `is_port_open(port_id)` - 检查串口是否打开

**信号**：
- `port_opened(str, SerialConfig)` - 串口成功打开
- `port_closed(str)` - 串口已关闭
- `data_received(str, bytes)` - 接收到数据
- `connection_lost(str, str)` - 连接丢失
- `error_occurred(str, str)` - 发生错误

## 串口页面 (pages/serial_page.py)

### 功能
1. **自动生成控制栏** - 按当前扫描到的串口数量自动为每个串口生成一行控制栏（无需手动点“新建”）
2. **自动刷新** - 页面可见时每 2 秒扫描一次端口；插拔设备会自动增删控制栏，另提供 Refresh 按钮手动刷新
3. **波特率选择** - 每个串口独立的波特率下拉框（可编辑，支持自定义波特率）
4. **串口开关** - 每个串口独立的 Connect / Disconnect 按钮，可同时打开多个串口
5. **连接常驻** - 切换页面不会关闭已打开的串口，只有手动断开或异常（设备掉线/读写异常）才会关闭
6. **交互控制台** - 页面底部文本框显示**第一个连接**的串口的收发数据；该串口关闭后自动顺延到下一个已连接串口
7. **HEX 视图** - 控制台右上角 HEX 开关。开启后严格按字节显示（`RX nB: 0A 0D ...`）；关闭时按文本显示：
   - `CRLF` 合并为一次换行，单独 `CR` / `LF` 也换行，重复换行保留次数
   - 其它控制字节转义为 `\xNN`（如 `\x01`），因此二进制内容不会被误当作换行吞掉
   - 整帧只含空白/换行时（例如仅 `0A 0D`）退回字节显示，避免出现看不见内容的空行
   - 无法按 UTF-8 解码的帧直接按字节显示
   - 无论有没有 `0A 0D`，**每一帧都单独占一行**（帧由 12ms 静默间隔/4096B 上限切分）
8. **虚拟串口** - 通过注册表补充枚举，com0com 等虚拟串口也能被扫描到

## 与产测软件的集成

本串口模块设计用于产测软件的开发板交互，而非完整的串口调试工具。

### 主要区别
- **多串口支持** - 可同时打开多个串口测试多块开发板
- **简化功能** - 只提供核心的打开/关闭/读写功能
- **扩展性** - 易于在此基础上添加测试逻辑和数据解析

### 未来扩展方向
- 数据日志记录
- 自动化测试脚本执行
- 测试结果统计和报告
- 设备识别和自动配置
